# Riemann hypothesis in Lean

This repository mirrors Levent Alpöge’s claimed proof of the Riemann hypothesis in Lean. The entry point states that every nontrivial zero of the Riemann zeta function has real part ½. It also states the corresponding result for Dirichlet L-functions. [Theorem statements](src/Main.lean)

Alpöge’s announcement describes the claimed proof and links to the 14 parts of the original archive. [Source announcement](https://alpo.ge/remark.pdf)
